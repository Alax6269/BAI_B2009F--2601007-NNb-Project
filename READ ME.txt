-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
(1) To run the model locally use the command below :
-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

python train.py

python test.py

-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
(2)If wan to put images into the model and make it predict can use this command below: 
-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

python predict.py



-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
(3) To build and train the model locally from the device use this commands below :
-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

docker build -f Dockerfile.train -t nn-train .
docker run --rm --gpus all -v "${PWD}/data:/app/data" -v "${PWD}/models:/app/models" nn-train



-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
(4) To build and test the model locally from the device use this commands below :
-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

docker build -f Dockerfile.test -t nn-test .
docker run --rm -v "${PWD}/data:/app/data" -v "${PWD}/models:/app/models" nn-test



-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
(5) To test the model on any other device use this commands below in the powershell :
-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

docker pull kepli/fruit-classifier-test:latest
docker run --rm -v "${PWD}/data:/app/data" kepli/fruit-classifier-test:latest python test.py
